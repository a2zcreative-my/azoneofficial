## Previous Local Work — v1.174.4 — A table cell breaks on words

Three phone screenshots (22 September): the Attendance register with **STAFF** running down the page as S/T/A/F/F and a staff name one letter per line, the per-person summary the same, Payroll likewise. **The cause was v1.174.1's own fix.** `overflow-wrap: anywhere` on `.erp-card` is right for a flex row - an unbreakable run wraps inside the card instead of pushing it off the phone - and destructive inside a table: it drops a cell's MINIMUM content contribution to one character, so the automatic layout may squeeze that column to one character wide. Full record: CHANGELOG 1.174.4.
